7. Hooks — Low-Level Control

Hooks are event-driven scripts that fire before/after tool execution. The hook system has 30 hook events across session, prompt, tool, subagent, task, file, and notification phases.

Hook Types

Event When It Fires Can Block?
PreToolUse Before tool execution Yes
PostToolUse After tool completes No (already executed)
UserPromptSubmit User submits a prompt Yes
Stop Execution finishes No
SubagentStop Subagent finishes No

Hook Configuration Location

· Global: ~/.claude/settings.json
· Project: .claude/settings.json in your project directory

Example: Block Force Pushes to Main

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "bash -c 'if echo \"$CLAUDE_TOOL_INPUT\" | grep -q \"git push.*--force\"; then echo \"BLOCKED: Force push to main not allowed\" >&2; exit 1; fi'",
            "timeout": 5
          }
        ]
      }
    ]
  }
}
```

Example: Custom Python Hook

Hooks receive JSON via stdin and return JSON via stdout:

```python
#!/usr/bin/env python3
import json, sys

input_data = json.load(sys.stdin)
tool_name = input_data.get("tool_name")
tool_input = input_data.get("tool_input", {})

if tool_name in ["Write", "Edit"]:
    file_path = tool_input.get("file_path", "")
    if ".env" in file_path:
        print(json.dumps({
            "hookSpecificOutput": {
                "hookEventName": input_data["hook_event_name"],
                "permissionDecision": "deny",
                "permissionDecisionReason": "Cannot modify .env files"
            }
        }))
        sys.exit(0)

print(json.dumps({}))  # Allow
```
